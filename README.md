# Learper

Learper is a local macOS multiple-choice quiz app built with SwiftUI. Import a quiz generated by an agent, answer one question at a time, reveal hints, and review the explanations afterward. It starts with a sample quiz so you can try the interface immediately.

## Build and run

Requires macOS 13 or newer and Apple Command Line Tools (or Xcode). No account or API key is required.

```sh
./scripts/build_app.sh
open .build/app/Learper.app
```

The Swift Package can also be opened in Xcode from `Package.swift`. With a full Xcode installation, `swift build` and `swift test` are available. The build script uses `swiftc` directly so it also works on Macs with only Command Line Tools.

Run `./scripts/test.sh` for the full model, session, and persistence suite with a coverage report. It executes the same test cases through a small assertion adapter when only Command Line Tools are installed; Xcode uses XCTest directly via `swift test`. The quick integration smoke check remains available as `./scripts/smoke_test.sh`.

## Make a quiz with an agent

Give the agent [the question format](docs/QUESTION_FORMAT.md) and your notes or topic. Save its JSON response as a `.json` file and choose **Import JSON** in the app. You can also copy the whole JSON object and choose **Paste JSON**. A matching set ID replaces the earlier imported set.

The format includes question text, optional context, progressive hints, 2–6 choices, the correct choice ID, and an explanation. Rich text supports inline Markdown code, fenced code blocks in C, C++, Python, and Rust, plus inline `$...$` and display `$$...$$` LaTeX. Image metadata is reserved in the format, but images are not displayed in this version.

Imported quizzes are saved in `~/Library/Application Support/Learper/library.json`. Quiz content stays on the Mac. The app does not call a model or other service itself.

## Project map

- `Sources/Learper/QuizModels.swift`: v1 JSON data model and validation.
- `Sources/Learper/QuizLibrary.swift`: JSON import and local persistence.
- `Sources/Learper/QuizSession.swift`: answer, hint, and progress state.
- `Sources/Learper/ContentView.swift`: SwiftUI interface.
- `Sources/Learper/RichTextView.swift` and `Resources/Web`: offline rich-text rendering.
- `docs/QUESTION_FORMAT.md`: agent-facing generation contract.
- `Tests/LearperTests`: model and quiz behavior tests.

The renderer bundles Markdown-it, KaTeX, and highlight.js under their included licenses in `Resources/Web/vendor`. No external CDN is used at runtime. On macOS 26 with a recent Xcode compiler, the cards use the system glass effect. Earlier macOS versions use native translucent materials.

## Current scope

Learper handles imported single-answer MCQs. Sessions run in memory; imported sets persist, while answers and scores reset when the app quits or a set is reopened. Image fields are accepted for forward compatibility and intentionally ignored by the renderer.
